# Task-3-ComPract-2
Навчальне завдання з комп'ютерного практикуму №2 (завдання 3).

## Опис
Програма мовою C++, яка за введеним номером студента у списку виводить його прізвище та ініціали.

## Умова завдання
Написати програму мовою C++ з використанням оператора "switch-case": ввести номер студента та вивести його прізвище та ініціали.

## Вхідні дані
"number" – номер студента у списку (ціле число).

## Вихідні дані
- прізвище та ініціали студента з відповідним номером;
- якщо номера немає у списку, виводиться повідомлення про помилку.
